How each answer can be checked

Every answer from the live checkers says where it came from: which organisation scored the CVE and which CVSS version, or which place was matched, its coordinates and which data set was used. Unknown CVEs, unscored CVEs, unknown places and days that haven't finished return an error, so a miner is never marked wrong against a guessed reference.

The four endpoints are free and keyless:

https://telegraph-evaluator.vercel.app/api/truth/cve?cve_id=…
https://telegraph-evaluator.vercel.app/api/truth/weather?location=…&date=YYYY-MM-DD
https://telegraph-evaluator.vercel.app/api/truth/travel?route_or_flight=…
https://telegraph-evaluator.vercel.app/api/truth/b2b?domain=…
