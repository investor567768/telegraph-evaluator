Telegraph Evaluator: truth sources

Telegraph scores its miners by comparing their answers with a trusted reference. These are the references I contribute: public, keyless sources that give one checkable answer, and that return an error rather than a guess when they cannot.

CVE severity score

Official CVSS base score for a vulnerability. NIST's own score first; if NIST hasn't scored it yet, the reporting organisation's score from the official CVE record.

CVE_LOOKUP_CVSSVULNERABILITY_TRIAGE_GENERAL
Try CVE-2021-44228 (Log4Shell) or CVE-2024-3094 (xz backdoor).

What the weather actually was

A past day's high, low, rainfall and main weather at a named place, the side an old forecast is checked against. Any day back to 1940, in the place's own time zone.

WEATHER_FORECAST_VERIFY_GENERAL
Try "Lagos" and "Lagos, Portugal": same name, different place.

How each answer can be checked

Every answer from the live checkers says where it came from: which organisation scored the CVE and which CVSS version, or which place was matched, its coordinates and which data set was used. Unknown CVEs, unscored CVEs, unknown places and days that haven't finished return an error, so a miner is never marked wrong against a guessed reference.

Endpoints: https://telegraph-evaluator.vercel.app/api/truth/cve?cve_id=… and https://telegraph-evaluator.vercel.app/api/truth/weather?location=…&date=YYYY-MM-DD. Both are free and keyless.
